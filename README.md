---

## 📌 Project Overview

**BookSwapHub** is a web-based application developed as a college project to promote book sharing and sustainable reading practices. The platform allows users to list books they own, request exchanges, and connect with other readers in their community.

This system reduces the cost of purchasing books and encourages a sharing economy among students and book lovers.

---

## 🎯 Objectives

- Develop a user-friendly book exchange platform  
- Encourage reuse and sharing of books

## 🏗️ System Architecture

The system follows a Client-Server Architecture:

1. User interacts with the Frontend  
2. Frontend sends requests to Backend APIs  
3. Backend processes requests  
4. Database stores and retrieves data  
5. Response is returned to the user

## ⚙️ Installation & Setup

git clone https://github.com/sssaptal08-glitch/Book-Exchange-Store.git

### 1️⃣ Clone the Repository

cd Book-Exchange-Store

---

### 2️⃣ Install Dependencies

npm install

---

### 3️⃣ Configure Environment Variables

Create a `.env` file and add:

PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

---

### 4️⃣ Run the Application

npm start

---

Open your browser and visit:

http://localhost:5000
